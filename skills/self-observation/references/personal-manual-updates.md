# Personal manual updates

When the user rejects an observation, mark it withdrawn or revised with date and reason; do not keep reusing it as established evidence. Revisit only if new evidence is relevant and the user wishes to reconsider.

Keep goals, preferences, work conditions, communication, and boundaries separate. Accumulate observations before a revision. A proposal lists current text, proposed change, supporting evidence, counterevidence, and unresolved questions. Update only after owner confirmation and retain prior versions.
