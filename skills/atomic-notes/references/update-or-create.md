# Update or create

Search titles, aliases, keywords, sources, and nearby topic indexes; do not claim exhaustive semantic search without a tool that provides it.

- Same question and compatible evidence: update the existing note.
- Changed evidence: preserve the old conclusion's date and basis, add the new evidence and reason for change, and distinguish supplementation from reversal.
- Different scope: create only when independently useful and cross-link the scope difference.
- Overlapping fragments: choose a canonical note, preserve source locators and unique context, and preview a merge. Do not delete originals without authorization.
- A split must leave each resulting note understandable; preserve a map from old sections to new targets.
- A rename/move must check affected Markdown and Wikilinks, duplicate basenames, aliases, and inbound references. Preserve a redirect or update affected links within authorized scope; report unresolved links.
- Unclear value: retain in intake rather than force a new note.

Never silently overwrite conflicting evidence. Reuse prior checks only if their scope and freshness still fit.
