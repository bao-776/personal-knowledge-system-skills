# Obsidian Vault

Use Obsidian as an enhancement layer over portable Markdown.

## Workflow

1. Inspect the vault, local instructions, installed features, naming, and existing fields.
2. For YAML and Properties, read [references/properties-and-yaml.md](references/properties-and-yaml.md).
3. For links, read [references/wikilinks.md](references/wikilinks.md).
4. For native Bases, read [references/bases.md](references/bases.md).
5. For Home, Dashboard, and Index behavior, read [references/dashboard-patterns.md](references/dashboard-patterns.md).
6. Preserve existing conventions unless the user requested migration.
7. Validate syntax and unresolved links after edits. Distinguish file-level checks from visual GUI verification.

Use [assets/dashboard-template.md](assets/dashboard-template.md) and [assets/base-examples](assets/base-examples) only when those features serve an identified need.
