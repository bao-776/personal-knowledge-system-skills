# Retrospective

## Workflow

1. Identify project review or periodic review and load only the matching reference.
2. Gather event logs, decisions, results, prior goals, and validation evidence.
3. Interview one question at a time. Let the user answer with fragments; summarize and verify.
4. Separate facts, feelings, interpretations, results, external contributions, and capability evidence using [references/evidence-vs-impression.md](references/evidence-vs-impression.md).
5. For projects, read [references/project-review.md](references/project-review.md). For a week, month, quarter, or year, read [references/periodic-review.md](references/periodic-review.md).
6. Present the complete draft for factual and interpretive confirmation before writing.
7. End with a small decision, process change, or experiment that can be observed later.

Use the matching template in [assets](assets). Do not backdate later outcomes into an earlier period.
