# Decisions and evidence

Record problem, date, owner, options, chosen path, rationale, tradeoffs, assumptions, evidence, validation, and reversal condition. Separate confirmed facts from open questions. Attribute work to the user, collaborators, tools, and AI. Record significant events with occurrence date, source locator, result, and next action in the existing event log or status history; do not create a log for every trivial action. A checkpoint identifies completed source/destination pairs and unfinished steps.
