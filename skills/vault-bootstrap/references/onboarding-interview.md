# Onboarding interview

Ask one question at a time:

1. What recurring problem should the vault solve?
2. What observable result would make it useful?
3. Which inputs matter now?
4. What should be easy to retrieve?
5. Which outputs recur?
6. What is private, restricted, or public?
7. What may the assistant read and write?
8. What tools and conventions already exist?
9. How much maintenance is realistic?

Skip answered questions. End with a confirmed minimum design.
