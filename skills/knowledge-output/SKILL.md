# Knowledge Output

## Workflow

1. Build a brief using [assets/output-brief-template.md](assets/output-brief-template.md).
2. Confirm audience and intended action with [references/audience-and-purpose.md](references/audience-and-purpose.md).
3. Identify maintained sources and their versions using [references/source-versioning.md](references/source-versioning.md).
4. Apply the minimum disclosure required for the purpose using [references/disclosure-review.md](references/disclosure-review.md).
5. Present an outline when the output is public, sensitive, high-impact, or expensive to revise.
6. Draft, verify every factual claim, and record reviewer and delivery status.
7. If a source fact is wrong, correct the Raw/Wiki layer first and regenerate the output.

Do not expose internal reasoning, private examples, or unrelated preferences.
