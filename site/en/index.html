Clear boundaries before automation

  • AI inference is not recorded as fact
  • One success is not stable capability
  • Output does not become a source of truth
  • Candidate interests are not automatic goals
  • Writes require authorization
  • No third-party Obsidian plugin is required
  • Self-observation is not diagnosis
  • Public examples are fictional

Version 0.1.2 is released under the MIT License. Automated checks cover repository contracts, links, privacy, installation, and minimum-vault creation; they are not presented as complete live Codex behavior evaluation.

Frequently asked questions

These answers also define the current limits of the project.

Is this an Obsidian plugin?

No. It is a Codex skill suite built around portable Markdown files. Obsidian Properties, Wikilinks, Bases, and dashboard conventions are available as an optional adapter.

Can I use it with an existing vault?

Yes. The bootstrap workflow inspects existing structure and migration constraints instead of forcing a fixed directory design.

Will it modify files automatically?

Important writes and initial setup are previewed first. Without write authorization, the skills provide proposals only.

Does atomic note-taking mean splitting everything into tiny files?

No. A separate atomic note is useful only when one reusable question or conclusion deserves independent retrieval. Existing knowledge should be updated first.

Can it analyze my personality?

It supports evidence-based self-observation with context, confidence, alternatives, and counterevidence. It does not diagnose or infer a fixed personality from a single event.

Has the complete system been experimentally validated?

No. Individual modules draw from established work on provenance, note-taking, deliberate practice, experiential learning, and reflection. The complete suite still needs broader user feedback and live behavior evaluation.
