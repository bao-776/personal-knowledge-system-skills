# 测试覆盖矩阵

区分用例存在、执行记录和结果。cases.json 目前提供每个 Skill 的路由用例，以及部分授权、冲突和选择性核查场景；这不代表每个 Skill 的所有边界均被覆盖。

- 自动契约：结构、相对链接、安装文件一致性、评测清单格式、隐私模式。
- Agent 行为：真实运行时的触发、授权继承、原文保真、选择性核查、重复处理、输出与解释。无执行记录时全部为待验证。
- 上架兼容性：每个声明支持的工具需独立行为证据；文件格式兼容不等于行为兼容。

记录环境和模型版本、输入样本、实际行为、断言逐项结果、失败理由及复测结果。来源 snippets 不能作为全文已读记录。英文触发、批量中断、同名链接和更新失败必须增加针对性用例后再声明覆盖。

当前评测清单：16 个 Skill、25 个场景，包含单条抓录遇到 CAPTCHA 时停止、只读检索和变更影响等边界；清单校验通过仍不代表真实 Agent 行为已通过。

安装生命周期测试实际执行三个配置（6 / 10 / 16 个 Skill），五个新增模块的独立安装，以及更新、卸载备份与失败回滚；网页另需检查双语桌面/手机交互和无脚本回退。
