# 使用效果检查

这套系统是否有帮助，应由真实使用结果判断，而不是文件数量判断。

## 首版观察指标

| 问题 | 建议观察方式 |
|---|---|
| 能否轻松接住输入 | 一条普通资料能否在两分钟内进入合适位置 |
| 能否找回旧理解 | 用户能否在五分钟内找到相关笔记和来源 |
| 是否减少重复 | 同主题新资料是否优先更新或合并已有内容 |
| 项目能否接续 | 中断后能否恢复目标、位置、卡点和验证状态 |
| 复盘是否有作用 | 复盘是否产生一个可观察的决策、流程改变或实验 |
| 维护负担是否合适 | 用户是否愿意在下一个周期继续使用当前结构 |

这些时间值是首版观察基准，不是对所有人的硬性要求。实际评估应同时记录用户的工作类型、资料规模和可用时间。

## 不作为成功指标

- 笔记总数、标签总数或双链数量。
- 看完多少资源。
- AI 生成了多少内容。
- 一次项目成功后自行宣称已经稳定掌握。
