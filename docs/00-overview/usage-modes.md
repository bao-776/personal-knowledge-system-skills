# 使用模式

用户不需要一次启用全部系统。先选择能覆盖当前问题的最小模式，之后可以继续安装其他 Skill。

| 模式 | 包含 Skill | 适合场景 |
|---|---|---|
| `lightweight` | knowledge-vault、knowledge-intake、atomic-notes、knowledge-output、knowledge-retrieve、knowledge-capture | 收集资料、形成笔记、整理输出 |
| `growth` | lightweight，加 growth-system、project-lifecycle、retrospective、knowledge-impact | 学习、项目推进、能力证据和复盘 |
| `full` | 16 个 Skill | 建库、Obsidian、成长、项目、自我观察与输出的完整流程 |

`knowledge-vault` 是按已安装模块工作的总控入口。轻量与成长模式均包含它；独立安装总控不会自动安装全部子 Skill。缺少所需模块时明确报告限制。

模式不是身份标签。用户可以直接安装一个独立子 Skill，也可以随需求变化升级或缩小使用范围。
