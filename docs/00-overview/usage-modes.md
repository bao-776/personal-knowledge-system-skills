# 使用模式

用户不需要一次启用全部系统。先选择能覆盖当前问题的最小模式，之后可以继续安装其他 Skill。

| 模式 | 包含 Skill | 适合场景 |
|---|---|---|
| `lightweight` | knowledge-intake、atomic-notes、knowledge-output | 收集资料、形成笔记、整理输出 |
| `growth` | lightweight，加 growth-system、project-lifecycle、retrospective | 学习、项目推进、能力证据和复盘 |
| `full` | 11 个 Skill | 建库、Obsidian、成长、项目、自我观察与输出的完整流程 |

`knowledge-vault` 是完整套件的总控入口。安装它时，安装脚本会同时安装所有被它路由的子 Skill，避免出现总控能识别任务但无法执行子流程的情况。

模式不是身份标签。用户可以直接安装一个独立子 Skill，也可以随需求变化升级或缩小使用范围。
