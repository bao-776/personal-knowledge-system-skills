# 用户旅程

## 首次建库

用户可以先选择 [轻量、成长或完整模式](usage-modes.md)。需要完整建库时，系统逐题确认内容类型、检索方式、隐私边界和写入许可。系统先给目录与文件预览，再创建最小架构，并用一份低敏资料完成首次演练。

## 日常维护

新资料先进入摄入流程；系统搜索已有内容，优先更新，必要时创建原子笔记。内容按需进入成长、项目、自我观察或 Inspire Time。

## 周期维护

事件记录为复盘提供证据。复盘产生的变更先成为提案，确认后再更新规则、重点或个人说明书。

## 中断与恢复

工作中断后，总控先重建目标、已完成内容、当前状态、未决问题和已有验证，再从第一个尚未验证的步骤继续。缺少子 Skill 时明确提示安装或只提供有限预览，不声称完整流程已经执行。
