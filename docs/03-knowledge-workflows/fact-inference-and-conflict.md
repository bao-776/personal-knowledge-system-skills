# 陈述归属与核实状态

有出处不等于真实。陈述归属区分 source-claim、user-statement、user-judgment、author-opinion、ai-inference；核实状态区分 unchecked、supported、qualified、contradicted、unresolved、not-applicable。旧 fact 标签只表示有来源，未经核实不能当成已验证事实。

先按用户目标筛出核心事实前提、精确数字、因果、冲突及高影响信息，再联网追查原始实验、论文、数据或记录。普通摄入默认最多三个优先陈述组、每组两轮检索；合并同义项，未查项明确保留未核实状态，不做全篇逐句事实检查。预算不能让高风险建议依赖未经核实前提。

观点可保留为观点，其中的事实前提仍需筛查。方向和幅度分开核对。搜索无果不能判假；摘要不能冒充阅读全文；隐私材料不能原样发送搜索引擎。Raw 不变，Wiki 写限定结论、原始主张、核查来源及重要不确定性。
